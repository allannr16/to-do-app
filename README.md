# 📝 To-Do List Avançada - Projeto Acadêmico

Este projeto é uma aplicação de Lista de Tarefas (To-Do List) completa, desenvolvida como parte do currículo de **Engenharia de Prompts e Aplicações de IA** na **Universidade Cruzeiro do Sul**. O objetivo é demonstrar o domínio de manipulação do DOM, lógica de programação em JavaScript puro e design responsivo.

## 🚀 Funcionalidades

A aplicação conta com 12 requisitos fundamentais implementados:

1.  **Entrada de Dados:** Adição de descrição da tarefa.
2.  **Seletor de Prioridade:** Definição de níveis Alta, Média ou Baixa.
3.  **Adição Dinâmica:** As tarefas aparecem instantaneamente na lista sem recarregar a página.
4.  **Exibição Detalhada:** Mostra descrição, prioridade, data de criação e prazo.
5.  **Ação de Conclusão:** Sistema de "check" que risca o texto e altera a cor para cinza.
6.  **Gerenciamento Total:** Opções para **Editar** e **Deletar** tarefas.
7.  **Sistema de Filtros:** Ordenação por data de criação e prioridade (Crescente/Decrescente).
8.  **Feedback Visual:** Alertas de sucesso ao adicionar atividades.
9.  **Timestamp:** Registro automático da data e hora de criação da tarefa.
10. **Data de Entrega:** Campo opcional para definir prazos (Deadlines).
11. **Modo Noturno/Dia:** Alternância de tema com ícones de Sol e Lua.
12. **Lixeira Inteligente:** Botão flutuante para restaurar tarefas deletadas acidentalmente.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando o "Vanilla Web Stack" (sem frameworks externos):

* **HTML5:** Estrutura semântica da aplicação.
* **CSS3:** Estilização moderna com Variáveis CSS (para o Dark Mode) e Flexbox para responsividade.
* **JavaScript (ES6+):** Lógica de negócios, manipulação de arrays e gerenciamento de estado do DOM.
